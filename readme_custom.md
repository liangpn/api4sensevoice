### 新增功能1：支持录入音频或上传音频
1. 音频文件上传功能
支持选择任意格式的音频文件
自动转换为 16000Hz 采样率、单声道、16位 WAV 格式
保存到 speaker 目录下
2. 实时音频录制功能
直接通过浏览器录制音频
自动转换为要求的音频格式（16000Hz、单声道、16位 WAV）
支持开始/停止录制控制
3. 自定义文件名
可以为录制或上传的音频文件指定自定义名称
系统会自动添加 .wav 扩展名
4. 服务器端处理
新增 /upload-audio 接口处理音频文件上传
自动创建 speaker 目录（如果不存在）
返回上传结果和文件路径
5.安装依赖
pip install python-multipart

### 新增功能2：支持通过页面配置识别说话人，支持勾选多个说话人
配置说话人验证：
    勾选 "Speaker Verification"
    系统会自动加载 speaker 目录下的所有音频文件
    选择要验证的说话人（默认全选）
    可以点击"刷新说话人列表"更新列表
